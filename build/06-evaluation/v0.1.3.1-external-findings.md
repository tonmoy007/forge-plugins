## 🔧 IMPROVEMENT AREAS (6 found)

| ID | Area | Description |
|----|------|-------------|
| I-001 | `scripts/why.py` | **Case-sensitive gate ID lookup.** `why.py g1-001` fails while `why.py G1-001` works. Gate criteria always use uppercase IDs. `why.py` should case-normalize before lookup. |
| I-002 | `references/gate-criteria.md` | **check_srs_acceptance.py not implemented.** Gate G1-003 references `check-srs-acceptance.py` which doesn't exist in scripts/. Gate check gracefully logs "not yet implemented" — but the script path is hardcoded and never resolves. Should either create the stub or remove the gate. |
| I-003 | `scripts/sync-lessons.py` | **Fragile markdown parser.** `parse_lessons_md()` expects a very specific format (`### DATE — TITLE` heading + `- **Field**:` bold-field lines). The template in `tasks/lessons.md` doesn't show the expected format. Users who write free-form YAML entries won't get them synced. |
| I-004 | `scripts/extract-lessons.py` | **No `--cwd` flag.** Only forge script that doesn't support `--cwd`. Uses `--input`/`--output` directly. Inconsistent with all other forge scripts. |
| I-005 | Hooks / Session-start | **`~/.forge/global-lessons.yaml` has no TTL/cleanup.** Test data from pytest runs persists indefinitely (6 stale lessons with pytest temp paths). No mechanism to expire stale global lessons. |
| I-006 | `scripts/detect-project-type.py` | **"unknown" projects get 0 confidence.** Small/edge-case projects detected as "unknown" with no fallback suggestions. User must manually intervene. |

## 💡 FEATURE SUGGESTIONS (5 found)

| ID | Description |
|----|-------------|
| S-001 | **Cycle wrapping.** After stage 12 (Release), auto-increment `cycle` and reset `current_stage` to 0. Currently the pipeline has no concept of cycle completion. The `forge-retro` skill exists but isn't wired into the flow. |
| S-002 | **Gate-checker agent invocation.** `agents/gate-checker.md` exists and was planned (T-016, REQ-021) but no code invokes it. The gate-checker was designed to evaluate ambiguous gate results that `check-gate.py` can't resolve mechanically. Should be wired in, even as a fallback. |
| S-003 | **`forge-why` lowercase tolerance.** Accept `g1-001`, `G1-001`, `G1-001` interchangeably. Currently strict uppercase match. |
| S-004 | **Script-level test coverage target.** 21 scripts, only a few have dedicated unit tests. Adding `script_has_tests` style gates for forge's own scripts would catch regressions earlier. |
| S-005 | **Cross-project lessons expiry.** Global lessons with stale `last_used` (>30 days) could be auto-archived. Currently 6 stale lessons from April/May pytest runs persist in `~/.forge/global-lessons.yaml`. |
